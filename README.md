# ESP32 Supervisor + GNSS HAT

Raspberry Pi HAT with an ESP32-C6 supervisor, u-blox MAX-M10S GNSS receiver, and HAT ID EEPROM.

Open `hardware/Argus-RPI-HAT.kicad_pro` in KiCad 10. The folder includes the routed four-layer PCB, schematics, and custom footprints.

DRC/ERC reports are in `hardware/checks/` and use the project's configured rules. The board has not been hardware-tested; verify the fabrication stack-up and USB/GNSS impedance before ordering.
